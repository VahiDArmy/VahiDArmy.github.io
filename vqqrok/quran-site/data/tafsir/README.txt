# فایل‌های تفسیر

این پوشه باید فایل‌های تفسیر سورهٔ واقعه را داشته باشد:

```
499.json   ← آیات ۱ تا ۱۰
500.json   ← آیات ۱۱ تا ۵۶
501.json   ← آیات ۵۷ تا ۹۶
```

فایل‌ها را عیناً همان‌طور که هستند (بدون تغییر ساختار) اینجا کپی کنید.
ساختار مورد انتظار: `{ "content_id": 499, "text": "..." }`

سایت خودش متن مارک‌داون را بلوک‌بندی می‌کند، آیه‌ها و ترجمه‌ها را از هم جدا می‌کند و
صفحه‌بندی می‌سازد. نیازی به تبدیل یا دسته‌بندی دستی نیست.

اگر فایل دیگری اضافه کردید، نامشان را در `manifest.json` کنار همین فایل بنویسید.
