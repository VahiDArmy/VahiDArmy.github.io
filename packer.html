    How the packer works
    
    
    
    
  
    
  
    
    
    
      
    
        
    Rules
    
        
      
          
    • Every {[[FILE: path]]} … {[[END: path]]} pair is captured verbatim, byte for byte. Prose outside pairs is ignored.
      • 
          
    • The same path replaces the earlier copy, across pastes. The log says whether it was changed or identical.
      • 
          
    • A missing END keeps the block and flags it truncated; a mismatched END name flags it corrupt.
      • 
          
    • Flagged paths collect into a resend request; a later clean paste of the same path clears it.
      • 
          
    • The zip stores files uncompressed, sorted by path, with a fixed 2024-01-01 timestamp so identical packs produce identical bytes.
      •

    Tips
    
        
    Drop one or more .txt message files onto the paste zone — they are ingested exactly like a paste. Drop a non-message file and it is added as a file of its own (useful for packing source files). Click any file to preview, copy, or save it. Everything stays in this tab.
