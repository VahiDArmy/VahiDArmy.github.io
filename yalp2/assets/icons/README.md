# آیکن‌های PWA

سه فایل PNG زیر باید اینجا قرار بگیرند تا `manifest.json` و نصب PWA کار کند:

| فایل | ابعاد | توضیح |
|------|-------|-------|
| `icon-192.png` | 192×192 | آیکن استاندارد (منو، تب) |
| `icon-512.png` | 512×512 | آیکن با کیفیت بالا (splash) |
| `icon-maskable-512.png` | 512×512 | نسخهٔ maskable با حاشیهٔ ~20٪ — بخش مهم آیکن در دایرهٔ امن 80% وسط قرار بگیرد |

## چطور بسازی

1. از SVG لوگو (همان سبد خرید با گرادیان بنفش-فیروزه‌ای) یک تصویر 512×512 بساز.
2. به [realfavicongenerator.net](https://realfavicongenerator.net) برو، آپلود کن.
3. سه PNG بالا را دانلود و در این پوشه بگذار.

## اگر نداشتی

سایت به کار خود ادامه می‌دهد — مرورگر آیکن پیش‌فرض نشان می‌دهد. فقط نصب PWA زیبایی کمتری دارد.
