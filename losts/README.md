# شادی‌یار (Joyyar) 🌻

وب‌اپلیکیشن **ثبت شادی‌های روزانه** با تمرکز روی زمان، پول و سرمایه‌ای که برای خودت خرج می‌کنی.

- زبان: فارسی
- جهت: RTL
- طراحی: مدرن، واکنش‌گرا، با حالت روشن/تاریک
- بک‌اند: Supabase (احراز هویت + دیتابیس)

## راه‌اندازی

1. **اسکیمای دیتابیس را اجرا کن**
   فایل `sql/joy_schema.sql` را در SQL Editor پروژهٔ Supabase خودت اجرا کن.
   این فایل فقط جدول‌های مخصوص این پروژه را می‌سازد (همه با پیشوند `joy_`) و به دیگر جدول‌ها دست نمی‌زند.

2. **فایل‌ها را سرو کن**
   این پروژه با ES Module مستقیم مرورگر کار می‌کند. یک سرور استاتیک ساده کافی است:
   ```bash
   python3 -m http.server 8080
   ```
   یا هر سرور دیگر. سپس در مرورگر `http://localhost:8080` را باز کن.

3. **احراز هویت**
   - ثبت‌نام با ایمیل/رمز
   - ورود با ایمیل/رمز
   - ورود با لینک جادویی
   - بازیابی رمز عبور

   اگر در Supabase گزینهٔ Email Confirmation فعال است، بعد از ثبت‌نام باید ایمیل تأیید را باز کنی.

## امکانات

- **داشبورد**: آمار امروز، این هفته، این ماه، رکورد پیوسته، دستاوردها
- **ثبت شادی**: عنوان، توضیح، ایموجی، دسته، شدت شادی (۱ تا ۱۰)، هزینه، زمان، حال قبل/بعد، مکان، همراهان، برچسب‌ها، موردعلاقه
- **دفتر شادی**: جستجو، فیلتر دسته، فیلتر بازه، مرتب‌سازی (جدید، قدیم، گران، شاد)
- **تقویم**: نمایش ماه‌های شمسی، شدت شادی هر روز، هزینه و زمان ماهانه، پنل روز
- **تحلیل**: نمودار خطی، دونات دسته‌ها، هزینه به تفکیک دسته، روزهای هفته، نقشهٔ حرارتی سال، پرتکرارترین برچسب‌ها، بینش‌های شخصی
- **هدف‌ها**: هدف با نوع (تعداد/هزینه/زمان/امتیاز)، دوره (هفته/ماه/سال/کل)، مهلت، دسته، پیشرفت و تکمیل
- **آرزوها**: لیست آرزوها با هزینهٔ تخمینی، اولویت، دسته، لینک و تیک انجام
- **تأمل‌ها**: یادداشت شبانه با حالت، متن، شکرگزاری
- **تنظیمات**: نام، تم، واحد پول، هدف روزانه، آمار، پشتیبان JSON، همگام‌سازی، پاک کردن داده‌ها، خروج

## نکات فنی

- Supabase Client از CDN بارگذاری می‌شود (بدون نیاز به build).
- تمام درخواست‌ها با `row level security` فقط توسط صاحب داده قابل دسترسی هستند.
- تم روشن/تاریک در `localStorage` ذخیره می‌شود.
- میانبرها: `Ctrl+K` برای جستجو در دفتر شادی، `Esc` برای بستن مودال.
