Browser workspace (OPFS) not run

Writes, reads, verifies, renames, deletes files in browser storage. This is where the agent will work.

Device folder link not run

Links a real folder on your phone. Pick an empty folder (e.g. Documents/qwen-test). The screen may switch to the system file picker — that's normal.

ZIP import/export not run

Creates and extracts a ZIP in memory, verifies contents, and offers a download.

OpenRouter connection not run

Paste your OpenRouter API key (openrouter.ai → Keys). It is stored only on this device and sent only to OpenRouter. Uses ~4–8 of your 50 daily free requests.

Agent loop test not run

The model must create 3 files via batched JSON actions, read them back to verify, then finish. The app independently checks the results — the model's word is not trusted.

Python runtime (Pyodide) not run

Downloads Python (~10 MB, one time, then cached) into a background worker. Then runs a syntax check and real pytest — including one intentionally failing test, to prove it detects failures honestly.

Web build & sandboxed preview not run

Bundles a 2-file JS project with esbuild (WebAssembly), runs it in a locked-down iframe, and checks the rendered output. Then runs a broken variant to prove errors are captured.
